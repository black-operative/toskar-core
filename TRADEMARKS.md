# Trademark policy

Copyright and trademark are different. The [GNU Affero General Public License](LICENSE) covers the source code in this repository. It does not grant permission to use Toskar trademarks, logos, Rune-Y artwork, the Ratatoskr mascot, or other Toskar branding. Toskar was called Yggdrasil before October 2026; this policy covers that name and its branding too.

You may use the marks to refer to the project in ordinary speech, including:

- "compatible with Toskar"
- "fork of Toskar Core"
- discussion and documentation that name the upstream project

A fork should use its own name, icon, and visual identity. Do not present an unofficial build as an official Toskar release, and do not use the marks in a way that suggests YEIXIO LLC produced or endorses that build.

Brand assets in this repository:

- The Toskar mark (the logo), which draws Yggdrasil, the world tree. Its source is `docs/brand/logo/`; `docs/brand/toskar-logo.png`, `assets/brand/generated/`, and the icons in `web/public/` are rendered from it.
- Ratatoskr, the Toskar mascot: the squirrel character, his poses, and his artwork (`docs/brand/mascot/`, `web/src/lib/ratatoskr/`).

Logos and the mascot shipped with the web UI in this repository are for running Toskar Core. They are not a general brand license. A fork should not use Ratatoskr as its own mascot.
