# Governance

Toskar Core is maintained by YEIXIO LLC.

Maintainers decide what is merged and what is released. Community proposals are welcome as GitHub issues and, once enabled, GitHub Discussions. A useful proposal states the problem, who it is for, and whether it changes the HTTP API or the node protocol.

Major architectural changes should start as an issue or a discussion before a large pull request. That includes new runtimes, changes to pairing, and changes to placement.

Contribution does not grant maintainer status. Maintainer status is an explicit decision by the current maintainers.

Contributions are covered by the [Toskar Contributor License Agreement](CLA.md). See [CONTRIBUTING.md](CONTRIBUTING.md) before sending code.

Day-to-day discussion should stay in this repository. Suggested Discussion categories, after Discussions are enabled:

- General
- Ideas
- Hardware & Runtimes
- Show and Tell
- Help
